# Temperature-Humidity-Monitor
This project is a simple but fully functional **Temperature & Humidity Monitoring System** built using:

- **Arduino Uno**
- **DHT11 sensor**
- **128x32 SSD1306 SPI OLED display**
- C++ code using **hardware SPI** for fast graphics performance

The system displays live temperature and humidity values on the OLED screen and updates every second.

---

## 🚀 Features

- Real-time temperature (°C) and humidity (%) readings  
- Uses the **DHT11 sensor** with Adafruit library  
- Fast and smooth OLED updates using **Hardware SPI**  
- Clean UI optimized for a 128×32 pixel display  
- Serial Monitor output for debugging  
- Beginner-friendly, easy to replicate

---

## 🛠 Hardware Required

- Arduino Uno  
- DHT11 Temperature & Humidity Sensor  
- SSD1306 OLED Display (SPI version — 7 pins)  
- Breadboard  
- Jumper Wires
